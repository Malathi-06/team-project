# Advanced E-commerce Catalog

A scalable, full-featured **MERN Stack e-commerce platform** designed to support product browsing, secure user authentication, cart and checkout workflows, analytics, and role-based administrative and seller management.

---

## Project Overview

The **Advanced E-commerce Catalog** is a modern web-based e-commerce application built using the MERN stack.  
It goes beyond a basic shopping application by incorporating **enterprise-level features** such as role-based dashboards, audit logging, discount handling, wishlist management, and seller support.

The project follows a **client–server architecture**, ensuring modularity, scalability, and maintainability.

---

## Core Functionalities

### User Features
- Secure user registration and login using JWT authentication
- Browse products with detailed views
- Add/remove items from cart
- Wishlist management
- Checkout and order placement
- User profile management
- Access to support and policy pages

### Shopping & Transactions
- Dynamic product catalog
- Cart management
- Checkout workflow
- Order history tracking
- Review and rating system

---

## Admin & Seller Capabilities

### Admin Dashboard
- Centralized dashboard with analytics and insights
- Product creation, update, and deletion
- Order monitoring and processing
- User management
- Category management
- Discount and promotional handling
- Audit logs for tracking system activities

### Seller Dashboard
- Dedicated seller interface
- Seller-specific product management
- Order tracking for seller-listed products
- Multi-vendor support architecture

## Technology Stack

### Frontend
- **React 19** (Vite)
- **React Router DOM v7**
- **Lucide React** for icons
- **Recharts** for analytics and charts

### Backend
- **Node.js**
- **Express.js**

### Database
- **MongoDB**
- **Mongoose v9.1.2**

### Authentication & Security
- **JWT (JSON Web Tokens)**
- **bcryptjs** for password hashing

### Development Tooling
- **Concurrently** – run client and server together
- **Nodemon** – backend hot reloading
- **ESLint** – code quality and consistency
